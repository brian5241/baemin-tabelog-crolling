배민 업체 수집기 설명서

프로젝트 구조와 기능을 쉽게 알아보기

1. 이게 뭐하는 프로그램이야?

배달의민족(배민) 앱에 나오는 음식점 이름, 별점(평점), 리뷰 수를 자동으로 모아주는 프로그램이에요.

사람이 하나하나 보면서 적는 대신, 컴퓨터가 화면을 사진 찍고 → 글자를 읽고 → 정리해서 엑셀 파일로 저장해 줍니다.

수학 시험지를 카메라로 찍어서 앱이 문제를 읽어주는 것과 비슷해요. 이 프로그램은 배민 화면을 찍어서 음식점 정보를 읽어내는 거예요.

중복 제거
스크롤하다 보면 같은 가게가 또 나올 수 있어요. 이름이 80% 이상 비슷하면 같은 가게로 취급합니다.

목표한 업체 수를 채울 때까지 아래로 스크롤하면서 2~6번을 반복합니다.
결과 저장
모은 데이터를 엑셀 파일(.xlsx)과 JSON 파일로 저장합니다.

baemin-scraper/

├── config.json ← 설정값 모음 (리모컨)
├── install.cmd ← 필요한 패키지 설치 (더블클릭)

└── output/ ← 결과물이 저장되는 폴더
    ├── 배민_날짜_시간.xlsx ← 엑셀 결과
    ├── 배민_날짜_시간.json ← JSON 결과
    └── step_001.png ... ← 캡처 이미지들
학교에 비유하면: scraper.py는 공부를 실제로 하는 학생, config.json은 학생에게 지시를 내리는 선생님의 지시서, output/ 폴더는 학생이 정리해서 제출하는 과제 노트예요.

4. 핵심 기능 하나씩 뜯어보기

기능 1 OCR — 사진에서 글자 읽기

OCR은 Optical Character Recognition의 약자로, 사진 속 글자를 텍스트로 바꾸는 기술이에요.

이 프로그램은 두 가지 OCR 엔진을 지원해요:

엔진특징비용
easyocr (기본) 내 컴퓨터에서 직접 돌림. 약간 느리지만 무료 무료
anthropic Claude AI에게 사진을 보내서 읽어달라고 요청. 빠르고 정확 유료 (1장당 약 10~20원)

config.json에서 "engine": "easyocr" 부분을 바꾸면 엔진을 쉽게 전환할 수 있어요.

easyocr는 내 머릿속에서 직접 글자를 읽는 것이고, anthropic은 옆에 있는 똑똑한 친구에게 "이거 뭐라고 써있어?"라고 물어보는 것이에요.

기능 2 파싱 — 필요한 정보만 골라내기

OCR이 읽어낸 텍스트는 온갖 잡다한 글자가 섞여 있어요.

예를 들어 화면에는 "기본순", "배달팁", "음식배달" 같은 버튼 글자도 있고, "카페그리닝 ★4.8 (48)" 같은 음식점 정보도 있어요.

프로그램은 정규식(regex)이라는 패턴 매칭 도구를 써서:

  • "이름 + 숫자.숫자 + (숫자)" 패턴을 찾으면 → 업체명, 평점, 리뷰 수로 분류
  • "기본순", "배달팁" 같은 UI 텍스트 → 무시
  • 숫자만 있는 이름 → 무시
쏟아진 레고 조각 중에서 빨간색 블록만 골라내는 것과 비슷해요. 정규식은 "빨간색이고 네모난 것"처럼 조건을 미리 정해놓고 자동으로 골라내는 규칙이에요.

기능 3 평점 재시도 — 못 읽었으면 확대해서 다시

★ 기호는 OCR이 놓치는 경우가 많아요. 그래서:

  1. 평점이 빠진 업체를 발견하면
  2. 그 업체가 있는 줄의 위아래 20픽셀을 잘라내고
  3. 3배로 확대한 뒤
  4. 다시 OCR을 돌려서 평점을 찾아요
칠판 글씨가 안 보이면 돋보기로 확대해서 다시 보는 것과 같아요!

기능 4 사람처럼 스크롤하기

봇이 일정한 속도로 스크롤하면 앱이 눈치챌 수 있어요. 그래서:

  • 스크롤 시작·끝 위치를 매번 살짝 다르게 (좌우 흔들림)
  • 스크롤 사이에 1.8~3.5초 랜덤 대기
  • 12% 확률로 5~9초 긴 쉼 (사람이 메뉴를 읽는 것처럼)
로봇이 아니라 실제 사람이 폰을 넘기면서 메뉴를 구경하는 것처럼 행동하는 거예요. 가끔 멈춰서 고민하는 척도 해요!

기능 5 중복 제거 — 같은 가게 거르기

스크롤하면 이전 화면에 있던 가게가 다음 화면에도 나와요.

프로그램은 두 이름의 글자가 80% 이상 겹치면 같은 가게로 판단해요.

예시:

  • "카페그리닝" vs "카페그리닝 정발산점" → 같은 가게 (포함 관계)
  • "파스타입니다 일산점" vs "파스타엔우 일산후곡점" → 다른 가게 (겹침 73%)

5. config.json 설명

설정뜻기본값
ocr.engine어떤 글자 인식 엔진을 쓸지easyocr
ocr.gpu그래픽카드로 빠르게 처리할지false (CPU만)
ocr.mag_ratio이미지 확대 비율0.85
scroll.pause_min/max스크롤 후 쉬는 시간 범위1.8~3.5초
scroll.long_pause_chance길게 쉴 확률12%
collect.max_no_new새 업체 없으면 몇 번 후 포기3번
collect.default_count기본 수집 목표30개
config.json은 왜 필요할까?
코드를 직접 수정하지 않아도 이 파일만 고치면 동작 방식을 바꿀 수 있어요. 마치 게임 설정에서 난이도를 바꾸는 것처럼요!

6. 어떤 기술이 쓰였어?

도구역할
Python프로그래밍 언어. 모든 코드가 Python으로 짜여 있어요

정규식 (regex)텍스트에서 특정 패턴을 찾아내는 규칙 언어

7. 어떻게 실행해?

패키지 설치 (처음 한 번만)
install.cmd를 더블클릭해요. 필요한 도구들이 자동으로 설치됩니다.
BlueStacks에서 배민 앱 열기
블루스택스를 실행하고, 배민 앱에서 원하는 카테고리(양식, 중식 등)의 업체 목록 화면을 띄워 놓아요.
수집 시작
run.cmd를 더블클릭하면 수집이 시작돼요. 화면을 자동으로 넘기면서 업체를 모아줍니다.
결과 확인
output 폴더에 엑셀 파일이 생겨요. 열어보면 업체명, 평점, 리뷰 수가 깔끔하게 정리되어 있어요!
긴급 중단: 수집 중 마우스를 화면 왼쪽 위 구석으로 옮기면 바로 멈춰요.
