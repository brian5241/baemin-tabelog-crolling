배민 업체 수집기 v2.0

BlueStacks + OCR 기반 배달의민족 업체 자동 수집 도구 · 2026-10-13

개요

BlueStacks 에뮬레이터에서 실행 중인 배민 앱 화면을 자동으로 캡처하고, OCR(글자 인식)로 업체명 / 평점 / 리뷰 수를 추출하여 엑셀 및 JSON 파일로 저장하는 자동화 스크립트.

동작 흐름

창 감지→ 스크린샷→ OCR→ 파싱→ 평점 재시도→ 중복 제거→ 스크롤→ 반복→ 저장

목표 수를 채우거나 3회 연속 새 업체가 없을 때까지 자동 반복합니다.

파일 구조

baemin-scraper/
├── scraper.py ── 메인 스크립트 (캡처, OCR, 파싱, 스크롤, 저장)
├── config.json ── 설정 (엔진, 스크롤 타이밍, 수집 옵션)
├── install.cmd ── 의존성 설치 (더블클릭)
├── run.cmd ── 수집 실행
├── test.cmd ── 1회 캡처 테스트
└── output/ ── 결과 (xlsx, json, 캡처 이미지)

핵심 기능

기능설명
OCR 엔진 선택 easyocr(로컬, 무료) 또는 anthropic(Claude API, 유료). config.json에서 전환
한국어 인식 easyocr CRAFT + ResNet + LSTM 기반 한/영 동시 인식
2단계 정규식 파싱 패턴1: 이름+평점+리뷰 · 패턴2(fallback): 이름+리뷰(평점 없음). UI 텍스트 필터링 적용
평점 복구 ★ 누락 시 해당 영역 크롭 → 3배 확대(bicubic) → mag_ratio 1.5로 재OCR
퍼지 중복 제거 한글 기준 문자 겹침 80% 이상이면 동일 업체로 판단. 평점/리뷰 자동 병합
봇 감지 회피 랜덤 스와이프 좌표, 1.8~3.5초 대기, 12% 확률 장기 휴식(5~9초)
결과 저장 스타일 적용 엑셀(.xlsx) + JSON 동시 출력

기술 스택

패키지역할

config.json 주요 항목

키기본값설명

ocr.gpufalseGPU 가속 여부
