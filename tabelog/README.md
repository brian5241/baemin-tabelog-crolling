# tabelog

타베로그(Tabelog) 가게 데이터를 기반으로, 스무고개 형식의 소거법 필터를 통해 특정 지역 맛집 후보군을 추천하는 개인용 앱.

- 데이터는 자동 크롤링 없이, 사용자가 앱 안 브라우저로 직접 연 타베로그 페이지를 저장해서 모음 (자세한 내용은 설계 문서 1-1)
- 결과는 단일 정답이 아니라 조건에 맞는 여러 후보군으로 남음 (Akinator식 단일 정답 추론과 반대)
- 사용자는 "이건 아니야"를 골라 후보를 소거해나가는 방식으로 진행
- 질문은 음식점/카페·디저트/술집/빵·과자 카테고리에 따라 분기됨
