## 보존 규칙

1. 할인가는 일반 가격과 별도 열에 저장한다. 사용자 혜택을 모든 사용자에게 적용되는 가격이라고 표현하지 않는다.
2. 배달팁·예상 배달시간은 주소와 주문 조건 등에 종속된 화면 정보이므로 기본 업체 정보에 고정값으로 넣지 않는다. 필요할 때 별도 관측값으로 저장하되 정확한 사용자 주소는 수집하지 않는다.
3. `90+`는 90으로 치환하지 않는다. 실제 집계 기간도 화면에서 확인되지 않았다.
4. 미확인 가격을 0으로 저장하지 않는다. 내부값은 null, 상태 열에 `화면 잘림` 등 사유를 저장하고 표시에서는 `정보 없음`으로 쓴다.
5. 전화번호는 문자열로 저장한다. 050 번호를 원래 매장 전화번호로 단정하지 않는다.
6. 업체와 메뉴는 서로 다른 행 구조를 가진다. 여러 메뉴를 업체명만으로 연결하지 말고 내부 업체 ID를 쓴다.
7. 스크린샷에서 확인한 값과 추정값을 섞지 않는다. 수집 시각과 실제 원본 촬영 시각을 구분한다.
8. 외부에서 읽은 문자열을 Excel 수식으로 실행하지 않도록 텍스트로 저장한다. 평점·금액 등 숫자 필드만 검증 후 숫자로 변환한다.
